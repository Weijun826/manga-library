# 漫畫書庫

Windows 專用、資料保留在本機的實體漫畫收藏管理程式。

## 功能

- 記錄系列、版本、卷冊、ISBN、擁有／已讀／願望狀態
- 編輯系列資料，替連載作品新增卷冊
- 使用本機 JPG、PNG 或 WebP 漫畫封面
- 更新前自動備份 SQLite 書庫
- 從桌面捷徑啟動，後續版本可在程式內更新

## 安裝與資料

第一次下載 Release 中的 Windows NSIS 安裝程式並安裝；Windows SmartScreen 可能在第一次安裝時要求確認。之後從桌面的「漫畫書庫」捷徑啟動，程式發現新版本時會顯示「立即更新」。

漫畫紀錄與封面只存放於目前 Windows 使用者的 Tauri app-data 目錄，不會上傳到 GitHub。安裝更新不會刪除既有資料；更新前備份保留在同一 app-data 目錄的 `backups` 資料夾。
